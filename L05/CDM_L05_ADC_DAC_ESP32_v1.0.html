Ce investigați

Un nod de măsurare transformă tensiunea senzorului într-un cod și, uneori, un cod într-o tensiune. Aici verificați pe varianta voastră cele patru decizii din C05: rezoluția, domeniul de intrare, calibrarea și ieșirea analogică.

Ipotezele modelului

Convertoare ideale, cu excepția referinței din Experiment 3. Domeniile de atenuare sunt cele recomandate în ESP-IDF v4.4. DAC-ul ESP32 are 8 biți și ieșire 0…3,3 V. Nu se modelează zgomotul și neliniaritatea.

Aceasta este o simulare. Aplicația nu se conectează la placă și nu transmite note. Rezultatele sunt calcule de proiectare, nu măsurări.

Breviar

Cuantizarea
q = FSR / 2n · cod = ⌊U / q⌋ (limitat la 2n − 1) · Urec = (cod + ½)·q · |eroare| ≤ q/2

Toate tensiunile dintr-o treaptă dau același cod. Peste FSR codul rămâne 2n − 1 (saturație).

Canale și atenuare pe ESP32

Cu Wi-Fi pornit, ADC2 nu poate fi folosit: senzorul analogic merge pe ADC1, GPIO32–39. Se alege cea mai mică atenuare al cărei domeniu recomandat cuprinde tot semnalul. q = (limita de sus a domeniului)/4096.

Referința internă
afișat = U · 1100 / Vref · eroare relativă = (afișat − U) / U · 100 %

Vref real variază între cipuri, aproximativ 1000…1200 mV. Eroarea este sistematică: nu dispare prin mediere; se corectează prin calibrare (analogReadMilliVolts în Arduino).

DAC și PWM
UDAC = D · 3,3 / 256 · D = round(Ut · 256 / 3,3) · Umedie PWM = (umplere/100) · 3,3 V · fc = 1 / (2πRC)

DAC-ul ESP32 are 8 biți pe GPIO25 și GPIO26. Pentru PWM, filtrul trebuie să aibă fc mult sub fPWM (raport de cel puțin 10, de preferat 100).

Parametrizarea după N

Experiment 1: n = 8, 10 sau 12 biți pentru N mod 3 = 0, 1, 2; FSR = 1000, 2450 sau 3300 mV pentru (N + 1) mod 3 = 0, 1, 2; U = 100 + 23·N mV. Experiment 2: senzor 200…(700 + 55·N) mV. Experiment 3: Vref = 1000 + (37·N mod 201) mV, U = 1500 mV. Experiment 4: Ut = 0,50 + 0,08·N V; fPWM = 1, 5 sau 10 kHz și C = 0,1, 0,47 sau 1 µF pentru N mod 3 = 0, 1, 2.

Păstrăm un singur nod autorizat, POST /data, pagina receptorului și GET /state. În locul valorii convenționale u transmitem o pereche T/RH și marcăm separat o citire DHT nereușită.

Ce diferențiem?

Achiziție nereușită ≠ mesaj pierdut ≠ mesaj recepționat dar învechit. Un HTTP 200 confirmă acceptarea cererii, nu corectitudinea fizică a temperaturii.

2. Varianta individuală N

Tₐ = 2,5 s ; Tₚ = 5 + (N mod 4) s ; Tᵥ = 1,5 Tₚ ; Tₗ = 3 Tₚ

Acești timpi sunt parametri didactici. Pragurile sunt depășite strict, nu la egalitate. Tₐ = 2,5 s respectă intervalul de citire ales pentru DHT22; programa de pe ESP32 folosește aceeași valoare. DHT11 poate avea cerințe de eșantionare diferite, însă păstrăm 2,5 s pentru compatibilitate.

4. Datele și vechimea lor

Temperatura T și umiditatea relativă RH

Linie violetă: temperatura simulată a senzorului; turcoaz: temperatura recepționată; linie întreruptă: RH recepționată (axa din dreapta). Găurile indică lipsa unei măsurători valide.

Vechimea mesajului și pragurile

Prag Tᵥ: date învechite; prag Tₗ: fără mesaje noi. La recepția unei erori de senzor, vechimea mesajului se resetează, dar măsurarea rămâne invalidă.

5. Chestiuni de studiat

  1. Aplicați N, calculați Tₚ, Tᵥ, Tₗ și observați identitatea nodului și cele două canale T/RH.
  2. Rulați fără defecte cel puțin 6 recepții. Calculați intervalele de comunicație și explicați diferența dintre Tₐ și Tₚ.
  3. După o recepție, întrerupeți legătura. Anticipați momentul trecerii la „Date învechite” și „Fără mesaje noi”.
  4. Restabiliți legătura și activați „Simulează defect DHT”. Se poate primi HTTP 200 pentru o măsurare invalidă? Explicați.
  5. Opriți emițătorul și apoi reporniți-l. Comparați repornirea cu simpla întrerupere a legăturii.
  6. În montajul real verificați citirea DHT22 și interogarea http://192.168.4.1. Notați erorile reale separat de cele simulate.
Întrebări recapitulative (minimum 5)
  1. Ce se întâmplă cu valorile memorate după oprirea emițătorului?
  2. De ce nu este corectă identificarea latentei folosind uptime-uri diferite?
  3. De ce HTTP 200 nu garantează că senzorul măsoară corect?
  4. Ce efect are Tₐ mult mai mic decât Tₚ?
  5. Ce diferență există între mesaj pierdut și probă locală netransmisă?
  6. De ce o probă invalidă nu trebuie înlocuită cu 0 °C?
  7. De ce receptorul păstrează un identificator și o sesiune?

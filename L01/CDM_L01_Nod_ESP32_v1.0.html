Ce investigați

Un nod de măsurare distribuit are patru sarcini: citește senzorii, verifică probele, le trimite prin rețea și se alimentează. În această aplicație proiectați un nod ESP32 cu un senzor digital DHT22 și un senzor analogic, fără placă reală.

Breviar

Regulile pinilor pe ESP32-DevKitC

ADC2 nu funcționează cât timp Wi-Fi este pornit (driverul Wi-Fi îl folosește). Un senzor analogic într-un nod Wi-Fi se pune pe ADC1: GPIO32, 33, 34, 35, 36 (VP), 39 (VN).

GPIO34–39 sunt doar intrări: nu pot genera semnalul de start al DHT, deci nu se folosesc pentru linia DATA.

GPIO6–11 sunt legați la memoria flash și nu se folosesc. GPIO1 și GPIO3 sunt UART0 (programare, Serial Monitor).

GPIO0, 2, 5, 12, 15 sunt pini de boot (strapping): nivelul lor la pornire influențează modul de pornire. Se evită pentru senzori când există alternative.

Achiziție și transmisie
probe pe mesaj = Tp / Ta · probe pe oră = 3600 / Ta · mesaje pe oră = 3600 / Tp
Tv = 1,5 · Tp (date învechite) · Tl = 3 · Tp (fără mesaje noi)

DHT22 acceptă cel mult o citire la 2 s; de aceea Ta ≥ 2,5 s. Fiecare mesaj HTTP poartă ultima probă; probele intermediare nu sunt mesaje pierdute.

Cadrul DHT22 (40 de biți)
RH = (RHsup·256 + RHinf) / 10 · T = ((Tsup & 0x7F)·256 + Tinf) / 10, negativă dacă bitul 7 din Tsup este 1
suma = (RHsup + RHinf + Tsup + Tinf) mod 256

Dacă suma calculată diferă de al cincilea octet, cadrul se respinge: citirea este invalidă (NaN, ok = 0), nu 0 °C.

Pasul q este un ordin de mărime: exactitatea reală este limitată de neliniaritate, referință (1000…1200 mV) și zgomot. Se tratează în C05.

Parametrizarea după N

LED impus: lista [2, 5, 13, 14, 16, 17, 18, 19, 21, 22, 23, 25, 26, 27], poziția (N−1) mod 14. Ta = 2,5 s, 3 s sau 4 s pentru N mod 3 = 0, 1, respectiv 2. Tp = 5 + (N mod 4) s. Umax = 0,40 + 0,05·N V. Cadrul A: RH = (400 + 7N)/10 %, T = (200 + 3N)/10 °C, iar pentru N multiplu de 10, T = −(50 + N)/10 °C. Cadrul B: cadrul A cu suma mărită cu 1.

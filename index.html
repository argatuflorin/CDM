L01 · NODUL DE MĂSURARE

Nodul ESP32 de măsurare

Placa ESP32-DevKitC pin cu pin, alegerea pinilor pentru DHT22 și un senzor analogic cu Wi-Fi pornit, ritmul achiziției și al transmisiei, decodarea unui cadru DHT. Fișă individuală după indicele N.

Deschide aplicația → L02 · PUNCT DE ACCES ȘI SERVER WEB

ESP32 ca punct de acces și server web

Rețeaua Wi-Fi creată de nod, rutele serverului HTTP testate dintr-un browser simulat, limita de clienți și programul Arduino generat pentru fiecare variantă N.

Deschide aplicația → L03 · COMUNICAȚII HTTP

Comunicația între două noduri ESP32

Transmiterea datelor prin HTTP, vechimea informației, întreruperea comunicației și repornirea nodului. Simulator cu date de test și fișă individuală după grupa și indicele N.

Deschide aplicația → L04 · ACHIZIȚIE DHT ȘI HTTP

Achiziția DHT și transmiterea între două ESP32

Senzor DHT11/DHT22, perioada de achiziție și cea de transmisie, probe invalide, date învechite și lipsa mesajelor. Simulator cu date de test și fișă individuală după grupa și indicele N.
